EffectZ portable mode

While this file sits next to effectz.exe, EffectZ keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the EffectZData folder beside it instead of
%APPDATA%\EffectZ. Copy the whole folder to move EffectZ with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\EffectZ unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\EffectZ) instead.
If EffectZData can't be written (for example on a read-only drive), EffectZ logs a
warning and uses %APPDATA%\EffectZ instead.
